# Mission: Engine Hire — the value it delivers to customers

## Why
Understand Engine Hire (a staffing platform) well enough to explain, build around and measure the core levers of value it gives its customers, with a particular focus on workers/candidates. The learner is studying the domain, not (yet) working inside the company.

## Success looks like
- Name Engine Hire's customer groups and say what each one gets from it.
- Pitch the core value levers clearly, in plain language, with evidence.
- Judge which features move which lever (product prioritisation).
- Define metrics that would show each lever is working (e.g. time-to-fill, shift fill rate, no-show rate).

## Constraints
- Learning over multiple short sessions; stateful workspace.
- Public sources only (no inside access to Engine Hire data).

## Out of scope
- Engineering internals of the platform.
- Competitor deep-dives (until the core levers are solid).
